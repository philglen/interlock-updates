# Interlock 0.1.16

This macOS verification release exercises the complete automatic-update path after the portability benchmark work.

- Preserves the installed macOS runtime and shared application data profile.
- Includes the latest accessibility, API-contract, and reliability improvements.
- Retains the signed Sparkle updater and native **Check for Updates…** command.
- Adds no migration or reset of broker accounts, Telegram profiles, trade history, or chart settings.

After installation, future signed releases can be applied from **Interlock → Check for Updates…**.
