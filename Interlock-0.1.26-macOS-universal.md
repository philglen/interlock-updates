Interlock 0.1.26
================

This macOS update improves the chart workspace and fixes multi-channel copy
trading controls.

- Adds Fair Value Gap overlays to the chart.
- Makes Signal Bot Entries toggles independent per Telegram channel, even when
  several channels share the same broker account.
- Removes `(currency unknown)` from activity P&L rows and uses the selected
  display currency fallback for older activity records.

The application remains Developer ID signed, notarized, stapled, and delivered
through the Sparkle update feed.
