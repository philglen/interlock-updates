# Interlock 0.1.8 Private Alpha

This release adds a full-screen multi-chart workspace with broker instrument search and up to six responsive charts.

Chart improvements include multi-position entry/stop/target overlays, M1 through D1 timeframes, localised chart times, toggleable OHLC, Bollinger Bands, ATR-scaled support and resistance zones, candle-pattern annotations, compact controls, and a stable risk-panel layout.

Open positions can now be historically backtested from their current price, stop, and target. Copy-trading lot sizes, fallback risk, and daily quotas are stored independently for each Telegram channel.
